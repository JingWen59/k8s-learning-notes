## 二、基础环境配置（4 台机器都执行）

### 2.1 配置静态 IP

编辑 `/etc/sysconfig/network-scripts/ifcfg-XXX`（网卡名根据实际）：

\```
BOOTPROTO=static
ONBOOT=yes
IPADDR=192.168.105.128   # 每台不同
NETMASK=255.255.255.0
GATEWAY=192.168.105.2
DNS1=8.8.8.8
\```

重启网络：
\```bash
systemctl restart network
\```

### 2.2 设置主机名

\```bash
# 每台机器分别执行
hostnamectl set-hostname k8s-master1   # master1 上
hostnamectl set-hostname k8s-master2   # master2 上
hostnamectl set-hostname k8s-master3   # master3 上
hostnamectl set-hostname k8s-worker1   # worker1 上
\```

### 2.3 配置 hosts

4 台机器都写入：

\```bash
cat >> /etc/hosts << EOF
192.168.105.128 k8s-master1
192.168.105.129 k8s-master2
192.168.105.130 k8s-master3
192.168.105.131 k8s-worker1
192.168.105.200 k8s-vip
EOF
\```

### 2.4 关闭防火墙

\```bash
systemctl stop firewalld
systemctl disable firewalld
\```

### 2.5 关闭 SELinux

\```bash
setenforce 0
sed -i 's/^SELINUX=enforcing$/SELINUX=disabled/' /etc/selinux/config
\```

### 2.6 关闭 Swap

\```bash
swapoff -a
sed -i '/swap/d' /etc/fstab
\```

### 2.7 禁用 PackageKit（如果是桌面版）

\```bash
systemctl stop PackageKit 2>/dev/null
systemctl disable PackageKit 2>/dev/null
\```

### 2.8 升级内核（CentOS 7.0 必做）

\```bash
# 安装 elrepo 仓库
rpm --import https://www.elrepo.org/RPM-GPG-KEY-elrepo.org
yum install -y https://www.elrepo.org/elrepo-release-7.0-3.el7.elrepo.noarch.rpm

# 安装 ml 内核
yum --enablerepo=elrepo-kernel install -y kernel-ml

# 设置默认启动内核
grub2-set-default 0
grub2-mkconfig -o /boot/grub2/grub.cfg

# 重启
reboot
\```

重启后验证：
\```bash
uname -r
# 应该是 5.x 或 6.x
\```

### 2.9 加载内核模块

\```bash
cat > /etc/modules-load.d/k8s.conf << EOF
br_netfilter
overlay
EOF

modprobe br_netfilter
modprobe overlay
\```

### 2.10 配置内核参数

\```bash
cat > /etc/sysctl.d/k8s.conf << EOF
net.bridge.bridge-nf-call-ip6tables = 1
net.bridge.bridge-nf-call-iptables = 1
net.ipv4.ip_forward = 1
EOF

sysctl --system
\```

### 2.11 更新基础软件包

\```bash
# 更新 ca-certificates（解决后续 TLS 问题）
yum update -y ca-certificates nss
update-ca-trust force-enable
update-ca-trust extract

# 更新 libseccomp（解决 runc 问题）
yum update -y libseccomp
\```

## 三、安装容器运行时 containerd

### 3.1 添加 docker 源（含 containerd）

\```bash
yum install -y yum-utils
yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

# 安装 containerd
yum install -y containerd.io
\```

### 3.2 解决 xfs ftype=0 问题（CentOS 7.3 之前必做）

检查 ftype：
\```bash
xfs_info / | grep ftype
# 如果显示 ftype=0，必须处理
\```

如果 ftype=0：

\```bash
systemctl stop containerd
rm -rf /var/lib/containerd/*

# 创建 ext4 镜像文件
dd if=/dev/zero of=/opt/containerd.img bs=1M count=5120
mkfs.ext4 -F /opt/containerd.img

# 挂载
mount -o loop /opt/containerd.img /var/lib/containerd

# 开机自动挂载
echo "/opt/containerd.img /var/lib/containerd ext4 loop,defaults 0 0" >> /etc/fstab
\```

### 3.3 配置 containerd

\```bash
mkdir -p /etc/containerd
containerd config default > /etc/containerd/config.toml

# 修改沙箱镜像源
sed -i 's|registry.k8s.io/pause|registry.aliyuncs.com/google_containers/pause|' /etc/containerd/config.toml

# 启用 systemd cgroup
sed -i 's|SystemdCgroup = false|SystemdCgroup = true|' /etc/containerd/config.toml

# 启用 config_path（镜像加速）
sed -i 's|config_path = ""|config_path = "/etc/containerd/certs.d"|' /etc/containerd/config.toml
\```

### 3.4 配置镜像加速

\```bash
mkdir -p /etc/containerd/certs.d/docker.io

cat > /etc/containerd/certs.d/docker.io/hosts.toml << EOF
server = "https://docker.io"

[host."https://docker.m.daocloud.io"]
  capabilities = ["pull", "resolve"]
  skip_verify = true
EOF
\```

### 3.5 启动 containerd

\```bash
systemctl enable containerd
systemctl start containerd

# 验证
crictl info | head -5
\```

## 五、配置高可用（3 台 Master 执行）

### 5.1 安装 keepalived 和 haproxy

\```bash
yum install -y keepalived haproxy
\```

### 5.2 配置 keepalived

#### Master1（MASTER 角色）

`/etc/keepalived/keepalived.conf`：

\```conf
! Configuration File for keepalived

global_defs {
   router_id LVS_DEVEL
}

vrrp_script check_haproxy {
    script "/bin/bash -c 'if [[ $(ss -tlnp | grep 8443) ]]; then exit 0; else exit 1; fi'"
    interval 3
    weight -2
    fall 10
    rise 2
}

vrrp_instance VI_1 {
    state MASTER
    interface eno16777736   # 根据实际网卡名修改
    virtual_router_id 51
    priority 100            # Master1: 100
    advert_int 1
    authentication {
        auth_type PASS
        auth_pass 12345
    }
    virtual_ipaddress {
        192.168.105.200
    }
    track_script {
        check_haproxy
    }
}
\```

#### Master2（BACKUP，priority=90）
#### Master3（BACKUP，priority=80）

只需改这三处：
\```
state BACKUP
priority 90  # 或 80
\```

### 5.3 配置 haproxy

3 台 Master 配置相同：

`/etc/haproxy/haproxy.cfg`：

\```conf
global
    log         127.0.0.1 local2
    chroot      /var/lib/haproxy
    pidfile     /var/run/haproxy.pid
    maxconn     4000
    user        haproxy
    group       haproxy
    daemon

defaults
    mode                    http
    log                     global
    option                  httplog
    option                  dontlognull
    option                  http-server-close
    option                  forwardfor    except 127.0.0.0/8
    option                  redispatch
    retries                 3
    timeout http-request    10s
    timeout queue           1m
    timeout connect         10s
    timeout client          1m
    timeout server          1m
    timeout http-keep-alive 10s
    timeout check           10s
    maxconn                 3000

frontend kubernetes-apiserver
    mode                 tcp
    bind                 *:8443
    option               tcplog
    default_backend      kubernetes-apiserver

backend kubernetes-apiserver
    mode        tcp
    balance     roundrobin
    server      k8s-master1   192.168.105.128:6443 check
    server      k8s-master2   192.168.105.129:6443 check
    server      k8s-master3   192.168.105.130:6443 check
\```

### 5.4 启动服务

\```bash
systemctl enable keepalived haproxy
systemctl start keepalived haproxy

# 验证 VIP
ip addr | grep 192.168.105.200
\```

## 六、初始化集群（Master1 上执行）

### 6.1 准备 kubeadm 配置文件

`/root/kubeadm-config.yaml`：

\```yaml
apiVersion: kubeadm.k8s.io/v1beta3
kind: InitConfiguration
localAPIEndpoint:
  advertiseAddress: 192.168.105.128
  bindPort: 6443
nodeRegistration:
  criSocket: unix:///run/containerd/containerd.sock
---
apiVersion: kubeadm.k8s.io/v1beta3
kind: ClusterConfiguration
kubernetesVersion: v1.30.0
imageRepository: registry.aliyuncs.com/google_containers
controlPlaneEndpoint: "192.168.105.200:8443"
networking:
  podSubnet: 10.244.0.0/16
  serviceSubnet: 10.96.0.0/12
\```

### 6.2 初始化

\```bash
kubeadm init --config /root/kubeadm-config.yaml --upload-certs | tee /root/kubeadm-init.log
\```

成功后会输出 join 命令，**复制保存**。

### 6.3 配置 kubectl

\```bash
mkdir -p $HOME/.kube
cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
chown $(id -u):$(id -g) $HOME/.kube/config

# 验证
kubectl get nodes
\```

## 七、其他节点加入集群

### 7.1 Master2 / Master3 加入

\```bash
# 用 init 输出的 control-plane 命令
kubeadm join 192.168.105.200:8443 --token <token> \
    --discovery-token-ca-cert-hash sha256:<hash> \
    --control-plane --certificate-key <key>

# 配置 kubectl
mkdir -p $HOME/.kube
cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
chown $(id -u):$(id -g) $HOME/.kube/config
\```

### 7.2 Worker1 加入

\```bash
# 用 init 输出的 worker 命令（没有 --control-plane）
kubeadm join 192.168.105.200:8443 --token <token> \
    --discovery-token-ca-cert-hash sha256:<hash>
\```

### 7.3 token 过期的处理

如果 token 过期（超过 24 小时）：

\```bash
# 在 Master1 上重新生成
kubeadm init phase upload-certs --upload-certs
kubeadm token create --print-join-command
\```

## 八、安装网络插件 Calico

### 8.1 下载 calico.yaml

由于 GitHub 在国内访问不稳定，推荐**在 Windows 浏览器**打开链接复制：

\```
https://raw.githubusercontent.com/projectcalico/calico/v3.28.0/manifests/calico.yaml
\```

保存到 Master1 的 `/root/calico.yaml`。

### 8.2 修改 Pod 网段

\```bash
sed -i 's|# - name: CALICO_IPV4POOL_CIDR|- name: CALICO_IPV4POOL_CIDR|' calico.yaml
sed -i 's|#   value: "192.168.0.0/16"|  value: "10.244.0.0/16"|' calico.yaml
\```

### 8.3 提前拉取镜像（4 台机器都执行）

\```bash
# 拉取 Calico 镜像
crictl pull docker.m.daocloud.io/calico/cni:v3.28.0
crictl pull docker.m.daocloud.io/calico/node:v3.28.0
crictl pull docker.m.daocloud.io/calico/kube-controllers:v3.28.0

# tag 成 K8s 期待的名字
ctr -n k8s.io images tag docker.m.daocloud.io/calico/cni:v3.28.0 docker.io/calico/cni:v3.28.0
ctr -n k8s.io images tag docker.m.daocloud.io/calico/node:v3.28.0 docker.io/calico/node:v3.28.0
ctr -n k8s.io images tag docker.m.daocloud.io/calico/kube-controllers:v3.28.0 docker.io/calico/kube-controllers:v3.28.0
\```

### 8.4 部署 Calico

\```bash
kubectl apply -f /root/calico.yaml

# 等待 Pod 启动（2-5 分钟）
watch kubectl get pods -n kube-system
\```

### 8.5 验证集群

\```bash
kubectl get nodes
\```

预期：所有节点 STATUS = Ready

## 十一、生产环境改进建议

| 当前架构 | 生产建议 |
|---------|---------|
| Master 2核2G | 4核8G+ |
| etcd 与 Master 共部署 | 独立 etcd 集群 |
| 单数据中心 | 多 AZ |
| 镜像依赖外网 | 自建 Harbor |
| 无监控 | Prometheus + Grafana |
| 无日志 | Loki / ELK |
| 无 CI/CD | ArgoCD |
| 无定期备份 | etcd 定期 snapshot |
